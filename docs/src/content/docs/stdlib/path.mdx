---
title: std::path
description: Build and split paths.
---

`std::path` splits paths and joins them. A path is text, so `std::text` works
on it too. Every function splits on POSIX `/` separators; a path is plain text,
not an operating-system path object.

<details>
<summary><code>base</code> — the last segment</summary>

```kiru
std::path::base(path<txt>) -> txt
```

- `path` — the path to read.
- Returns the text after the last `/`; the whole path when it has no `/`. An
  empty path has no segment and stops the run.

```kiru
std::print(std::path::base("/a/b/c"));   # c
```

</details>

<details>
<summary><code>dir</code> — a path without its last segment</summary>

```kiru
std::path::dir(path<txt>) -> txt
```

- `path` — the path to read.
- Returns the text before the last `/`, or `""` when there is none.

```kiru
std::print(std::path::dir("/a/b/c"));   # /a/b
```

</details>

<details>
<summary><code>ext</code> — the extension</summary>

```kiru
std::path::ext(path<txt>) -> txt
```

- `path` — the path to read.
- Returns the text after the last `.` of the last segment, or `""` when the last
  segment has no dot.

```kiru
std::print(std::path::ext("archive.tar.gz"));   # gz
```

</details>

<details>
<summary><code>join</code> — join two path segments</summary>

```kiru
std::path::join(base<txt>, name<txt>) -> txt
```

Joins two path segments. An absolute `name` replaces `base`, an empty `base` is
replaced by `name`, and a `base` already ending in `/` is used as is.

- `base`, `name` — the segments to join.
- Returns the joined path.

```kiru
let config<txt> = std::path::join(std::env::var("HOME"), ".config");
```

</details>

<details>
<summary><code>is_absolute</code> — whether a path is absolute</summary>

```kiru
std::path::is_absolute(path<txt>) -> txt
```

- `path` — the path to test.
- Returns `"true"` when the path starts with `/`, otherwise `"false"`.

```kiru
std::print(std::path::is_absolute("/a"));   # true
```

</details>
