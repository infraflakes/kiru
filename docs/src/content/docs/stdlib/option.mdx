---
title: std::Option
description: A value that may be present or absent.
---

`std::Option<T>` is an ordinary enum in the `std` namespace: a value that is
either present (`some`) or absent (`none`). [Absence](/concepts/absence/) covers
where it appears and what produces it.

```text
pub enum Option<T> { pub some(T), pub none };
```

Write it `std::Option`, or add `use std;` to write it bare. Both variants are
`pub`, so a program outside `std` constructs and matches them; the helpers are
bound functions, so calling one needs no `use`.

<details>
<summary><code>or</code> — the value, or a fallback</summary>

```text
option.or(fallback: T) -> T
```

- `fallback` — the value to use when `option` is `none`.
- Returns the value inside `some`, or `fallback`.

```kiru
use std;
use std::text;
fn main() {
  std::print("@("a=b".find("=").or(-1))");   # 1
};
```

</details>

<details>
<summary><code>contains</code> — whether a value is present</summary>

```text
option.contains() -> bool
```

- Returns `true` for `some`, `false` for `none`.

```kiru
use std;
use std::text;
fn main() {
  let found: std::Option<int> = "a=b".find("=");
  std::print("@(found.contains())");   # true
};
```

</details>
