---
title: Map
description: The Map record and its methods.
---

`Map<K, V>` is a declared `rec` in `std::dynamic`, an ordered association built
over a `Vec` of entries. A method whose first parameter is a `Map<K, V>` is
callable as `m.name(...)`; an associated function is reached as
`Map.name(...)`. `use std::dynamic;` brings the type and its methods into scope,
and a qualified `std::dynamic::Map` names the type without it. `Entry` and
`Map`'s field `entries` are private to `std::dynamic`, so a map is built and
read only through the methods below. [Maps](/concepts/maps/) covers the
narrative.

```text
use std::dynamic::Vec;
rec Entry<K, V> { pub key: K, pub value: V };
pub rec Map<K, V> { entries: Vec<Entry<K, V>> };
```

<details>
<summary><code>new</code> — the empty map</summary>

```text
std::dynamic::Map.new<K, V>() -> Map<K, V>
```

- Returns a map with no entries.

`new` has no argument to solve `K` and `V` from, so the call takes them from
its expected type: write the annotation and it works.

```kiru
use std;
use std::dynamic::Map;
fn main() {
  let m: Map<txt, txt> = Map.new();
  std::print("@(m.len())");   # 0
};
```

</details>

<details>
<summary><code>insert</code> — a new map with one key written</summary>

```text
map.insert(key: K, value: V) -> Map<K, V>
```

- `key` — the key to write.
- `value` — the value to store for it.
- Returns a new map: an existing key is replaced in place, a new key is
  appended. The map it is called on is unchanged.

```kiru
use std;
use std::dynamic::Map;
fn main() {
  let m: Map<txt, txt> = Map.new();
  m = m.insert("a", "1");
  let n: Map<txt, txt> = m.insert("b", "2");
  std::print("@(n.len())");   # 2
};
```

</details>

<details>
<summary><code>get</code> — the value stored for a key</summary>

```text
map.get(key: K) -> V
```

- `key` — the key to read.
- Returns the value stored for `key`. A key the map does not have has no value,
  so `get` stops the run with `get: the map has no entry for the key`; a caller
  that cannot promise the key is present uses `get_or`.

```kiru
use std;
use std::dynamic::Map;
fn main() {
  let m: Map<txt, txt> = Map.new();
  m = m.insert("a", "1");
  std::print(m.get("a"));   # 1
};
```

</details>

<details>
<summary><code>get_or</code> — the value stored for a key, or a fallback</summary>

```text
map.get_or(key: K, fallback: V) -> V
```

- `key` — the key to read.
- `fallback` — the value to return when the key is absent.
- Returns the value stored for `key`, or `fallback` when the map does not have
  it.

```kiru
use std;
use std::dynamic::Map;
fn main() {
  let m: Map<txt, txt> = Map.new();
  m = m.insert("a", "1");
  std::print(m.get_or("a", "missing"));   # 1
  std::print(m.get_or("z", "missing"));   # missing
};
```

</details>

<details>
<summary><code>contains</code> — whether a key is present</summary>

```text
map.contains(key: K) -> bool
```

- `key` — the key to test.
- Returns `true` or `false`.

```kiru
use std;
use std::dynamic::Map;
fn main() {
  let m: Map<txt, txt> = Map.new();
  m = m.insert("a", "1");
  std::print("@(m.contains("a")) @(m.contains("z"))");   # true false
};
```

</details>

<details>
<summary><code>keys</code> — the keys, in order</summary>

```text
map.keys() -> Vec<K>
```

- Returns a new vec of the keys in insertion order.

```kiru
use std;
use std::dynamic::Map;
fn main() {
  let m: Map<txt, txt> = Map.new();
  m = m.insert("a", "1");
  m = m.insert("b", "2");
  std::print(m.keys().join(","));   # a,b
};
```

</details>

<details>
<summary><code>values</code> — the values, in order</summary>

```text
map.values() -> Vec<V>
```

- Returns a new vec of the values in insertion order.

```kiru
use std;
use std::dynamic::Map;
fn main() {
  let m: Map<txt, txt> = Map.new();
  m = m.insert("a", "1");
  m = m.insert("b", "2");
  std::print(m.values().join(","));   # 1,2
};
```

</details>

<details>
<summary><code>len</code> — the number of entries</summary>

```text
map.len() -> int
```

- Returns the entry count.

```kiru
use std;
use std::dynamic::Map;
fn main() {
  let m: Map<txt, txt> = Map.new();
  m = m.insert("a", "1");
  m = m.insert("b", "2");
  std::print("@(m.len())");   # 2
};
```

</details>
