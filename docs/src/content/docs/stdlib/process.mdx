---
title: std::process
description: The command builder, quote, signals, sleeping, and the temporary directory.
---

`std::process` runs shell lines and argv-level processes, waits for them, and
signals them. [Running Commands](/commands/running-a-command/) and [Process
Groups](/commands/process-groups/) cover how these fit together; the syscall
natives underneath are in [std::syscalls](/stdlib/syscalls/).

<details>
<summary><code>command</code> — build a command</summary>

```text
std::process::command(line: txt) -> std::process::Command
```

Starts a command under construction. Each setting method returns a new
`Command`, so calls chain. `.run()` runs the line and returns the exit code as
an `int`; `.capture()` runs it and returns a `std::process::Output` of `code`,
`out`, and `err`. `Output`'s fields are `pub`, so a program reads them directly;
`Command` is a `pub` type a program can name and hold, but its fields are
private, reached only through its methods.

| | |
| --- | --- |
| `command.dir(path: txt) -> Command` | the working directory |
| `command.env(name: txt, value: txt) -> Command` | export one variable |
| `command.timeout(seconds: int) -> Command` | bound the run |
| `command.stream(stream: std::process::Stream, target: txt) -> Command` | attach `Stream.stdin`, `Stream.stdout`, or `Stream.stderr` to a path |
| `command.run() -> int` | run and return the exit code |
| `command.capture() -> std::process::Output` | run and return `code`, `out`, and `err` |

A stream is the declared enum `std::process::Stream`, whose variants are
`stdin`, `stdout`, and `stderr`; `stream` takes one of them, so a word that
names no stream does not type-check.

```kiru
use std;
use std::process;
fn main() {
  let code: int = std::process::command("echo hello").dir("/tmp").run();
  std::print("@(code)");
};
```

Related: [Running Commands](/commands/running-a-command/).

</details>

<details>
<summary><code>quote</code> — escape text as one shell word</summary>

```text
std::process::quote(text: txt) -> txt
```

Wraps `text` in single quotes and escapes every embedded quote as `'\''`, so
the shell reads exactly the text and nothing else.

```kiru
use std;
fn main() {
  let argument: txt = "a b";
  std::print(std::process::quote(argument));
};
```

</details>

<details>
<summary><code>wait_for</code> — reap a process and return its exit code</summary>

```text
std::process::wait_for(pid: int) -> int
```

Waits for the process named by `pid` and reaps it.

- `pid` — a pid returned by `std::syscalls::posix_spawn`.
- Returns the exit code as an `int`, or `128 + signal` when the process was
  signalled.

```kiru
use std;
use std::process;
use std::dynamic::Vec;
fn main() {
  let argv: Vec<txt> = Vec.new();
  argv = argv.push("/bin/true");
  let pid: int = std::syscalls::posix_spawn(argv);
  std::print("@(std::process::wait_for(pid))");
};
```

</details>

<details>
<summary><code>signal</code> — send a signal to a process group</summary>

```text
std::process::signal(pid: int, name: txt)
```

Sends a named signal to the process group led by `pid`.

- `pid` — a pid returned by `std::syscalls::posix_spawn`.
- `name` — `TERM`, `KILL`, `INT`, `HUP`, `QUIT`, `USR1`, `USR2`, `STOP`, or
  `CONT`.

```kiru
use std;
use std::process;
use std::dynamic::Vec;
fn main() {
  let argv: Vec<txt> = Vec.new();
  argv = argv.push("sleep");
  argv = argv.push("5");
  let pid: int = std::syscalls::posix_spawn(argv);
  std::process::signal(pid, "TERM");
  std::process::wait_for(pid);
  std::print("signalled");
};
```

</details>

<details>
<summary><code>sleep</code> — wait whole seconds</summary>

```text
std::process::sleep(seconds: int)
```

Waits for `seconds` whole seconds. A negative count stops the run.

```kiru
use std;
use std::process;
fn main() {
  std::process::sleep(0);
  std::print("waited");
};
```

</details>

<details>
<summary><code>temp_dir</code> — the temporary directory</summary>

```text
std::process::temp_dir() -> txt
```

Returns the temporary directory, from `TMPDIR` or `/tmp`.

```kiru
use std;
use std::process;
fn main() {
  std::print(std::process::temp_dir());
};
```

</details>
