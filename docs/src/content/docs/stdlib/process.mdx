---
title: std::process
description: Start, wait for, and signal processes.
---

`std::process` starts processes directly, waits for them, and signals them.
[Running Commands](/commands/running-a-command/) and [Process
Groups](/commands/process-groups/) cover how these fit together; `std::command`
is the shell builder.

<details>
<summary><code>spawn</code> — run an argv and return its pid</summary>

```kiru
std::process::spawn(argv: Vec<txt>) -> int
```

Runs `argv` without a shell, in its own process group, and returns the pid as an
`int`.

- `argv` — the program and its arguments, each an element of the vec.

```kiru
use std;
use std::text;
use std::vec;
use std::process;
let pid: int = std::process::spawn(["make", "-j4"]);
```

</details>

<details>
<summary><code>wait_for</code> — reap a process and return its exit code</summary>

```kiru
std::process::wait_for(pid: int) -> int
```

Waits for the process named by `pid` and reaps it.

- `pid` — a pid returned by `spawn`.
- Returns the exit code as an `int`, or `128 + signal` when the process was
  signalled.

```kiru
use std;
use std::text;
use std::vec;
use std::process;
let pid: int = std::process::spawn(["true"]);
let code: int = std::process::wait_for(pid);
```

</details>

<details>
<summary><code>signal</code> — send a signal to a process group</summary>

```kiru
std::process::signal(pid: int, name: txt)
```

Sends a named signal to the process group led by `pid`.

- `pid` — a pid returned by `spawn`.
- `name` — `TERM`, `KILL`, `INT`, `HUP`, `QUIT`, `USR1`, `USR2`, `STOP`, or
  `CONT`.

```kiru
use std;
use std::text;
use std::vec;
use std::process;
let pid: int = std::process::spawn(["sleep", "5"]);
std::process::signal(pid, "TERM");
```

</details>
