---
title: std::env
description: Read the environment and the working directory.
---

`std::env` reads environment variables and the process's directories.

<details>
<summary><code>var</code> — read an environment variable</summary>

```kiru
std::env::var(name<txt>) -> txt
```

- `name` — the variable to read.
- Returns its value, or `""` when it is unset.

```kiru
std::print(std::env::var("HOME"));
```

</details>

<details>
<summary><code>current_dir</code> — the working directory</summary>

```kiru
std::env::current_dir() -> txt
```

- Returns the process's working directory as text.

```kiru
std::print(std::env::current_dir());
```

</details>

<details>
<summary><code>temp_dir</code> — the temporary directory</summary>

```kiru
std::env::temp_dir() -> txt
```

- Returns the temporary directory, from `TMPDIR` or `/tmp`.

```kiru
std::print(std::env::temp_dir());
```

</details>
