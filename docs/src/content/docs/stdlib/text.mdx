---
title: std::text
description: Inspect and transform text, over the byte kernel.
---

`std::text` adds methods to `txt`. The byte kernel — `strlen`, `byte_at`,
`memchr`, and `substr` — is the four natives of the namespace, and the methods
above them are ordinary kiru in the same namespace. Length and byte indices
count bytes, not characters, so they line up with files and shell streams.
[Text](/concepts/text/) covers the literals, escapes, and interpolation.

<details>
<summary><code>strlen</code> — the number of bytes</summary>

```text
text.strlen() -> int
```

- Returns the byte count.

```kiru
use std;
use std::text;
fn main() {
  std::print("@("abc".strlen())");   # 3
};
```

</details>

<details>
<summary><code>byte_at</code> — the byte at an index</summary>

```text
text.byte_at(index: int) -> int
```

- `index` — a byte index.
- Returns the byte value there. An index outside the text stops the run.

```kiru
use std;
use std::text;
fn main() {
  std::print("@("abc".byte_at(1))");   # 98, the byte `b`
};
```

</details>

<details>
<summary><code>substr</code> — a range of bytes</summary>

```text
text.substr(start: int, end: int) -> txt
```

- `start`, `end` — the half-open byte range `[start, end)`.
- Returns the bytes in that range. A range outside the text, or one that splits
  a character, stops the run.

```kiru
use std;
use std::text;
fn main() {
  std::print("hello".substr(1, 3));   # el
};
```

</details>

<details>
<summary><code>memchr</code> — the first byte index of a needle</summary>

```text
text.memchr(needle: txt) -> std::Option<int>
```

- `needle` — the text to find.
- Returns `some(index)` for the byte index of the first occurrence, or `none`
  when it is absent. [Absence](/concepts/absence/) covers the optional value.

```text
use std;
use std::text;
match "hello".memchr("l") {
  std::Option.some(index) => { std::print("@(index)"); };   # 2
  std::Option.none => { std::print("absent"); };
};
```

</details>

<details>
<summary><code>find</code> — the first byte index of a needle</summary>

```text
text.find(needle: txt) -> std::Option<int>
```

The kernel under the method's name: `find` is `memchr`.

```kiru
use std;
use std::text;
fn main() {
  std::print("@("a=b".find("=").or(-1))");   # 1
};
```

</details>

<details>
<summary><code>contains</code> — whether text contains a needle</summary>

```text
text.contains(needle: txt) -> bool
```

- `needle` — the text to find.
- Returns `true` or `false`.

```kiru
use std;
use std::text;
fn main() {
  std::print("@("hello".contains("ell"))");   # true
};
```

</details>

<details>
<summary><code>starts_with</code> — whether text starts with a prefix</summary>

```text
text.starts_with(prefix: txt) -> bool
```

- `prefix` — the expected start.
- Returns `true` or `false`.

</details>

<details>
<summary><code>trim</code> — drop surrounding whitespace</summary>

```text
text.trim() -> txt
```

- Returns the text without leading or trailing ASCII whitespace.

```kiru
use std;
use std::text;
fn main() {
  std::print("  hi\n".trim());   # hi
};
```

</details>

<details>
<summary><code>number</code> — the number the text writes</summary>

```text
text.number() -> std::Option<int>
```

- Returns `some(number)` when the whole text is a decimal integer (a leading `-`
  negates), or `none` when it is not one.

```kiru
use std;
use std::text;
fn main() {
  std::print("@("42".number().or(0))");    # 42
};
```

</details>

<details>
<summary><code>split</code> — split text on a separator</summary>

```text
text.split(separator: txt) -> Vec<txt>
```

- `separator` — the text between parts. An empty separator stops the run.
- Returns the parts as a `Vec<txt>`.

```kiru
use std;
use std::text;
use std::dynamic::Vec;
fn main() {
  let parts: Vec<txt> = "a,b,c".split(",");
  std::print("@(parts.len())");
};
```

</details>

<details>
<summary><code>lines</code> — split text into lines</summary>

```text
text.lines() -> Vec<txt>
```

- Returns the lines, split on `\n`. A trailing newline adds no empty line.

```kiru
use std;
use std::text;
use std::dynamic::Vec;
fn main() {
  let lines: Vec<txt> = "a\nb\n".lines();
  std::print("@(lines.len())");
};
```

</details>

<details>
<summary><code>replace</code> — replace every occurrence</summary>

```text
text.replace(from: txt, to: txt) -> txt
```

- `from` — the text to replace. An empty `from` stops the run.
- `to` — the replacement.
- Returns a new text.

```kiru
use std;
use std::text;
fn main() {
  std::print("a-b-c".replace("-", "+"));   # a+b+c
};
```

</details>
