---
title: std::text
description: Inspect and transform text.
---

`std::text` measures, slices, searches, and transforms text. Length and slicing
count bytes, not characters, so they line up with files and shell streams.

<details>
<summary><code>len</code> — the number of bytes</summary>

```kiru
std::text::len(txt text) -> txt
```

- `text` — the text to measure.
- Returns the byte count as digit text.

```kiru
std::io::print(std::text::len("abc"));   # 3
```

</details>

<details>
<summary><code>slice</code> — a half-open byte range</summary>

```kiru
std::text::slice(txt text, txt start, txt end) -> txt
```

Returns the bytes from `start` up to but not including `end`.

- `text` — the source.
- `start`, `end` — byte indices as digit text. If an index is outside the text
  or falls inside a multi-byte character, the program exits with an error.

```kiru
std::io::print(std::text::slice("abcdef", "1", "4"));   # bcd
```

</details>

<details>
<summary><code>find</code> — the first byte index of a needle</summary>

```kiru
std::text::find(txt text, txt needle) -> txt
```

- `text` — the text to search.
- `needle` — the text to find.
- Returns the byte index of the first occurrence, or `""` when absent.

```kiru
std::io::print(std::text::find("hello", "l"));   # 2
```

</details>

<details>
<summary><code>trim</code> — drop surrounding whitespace</summary>

```kiru
std::text::trim(txt text) -> txt
```

- `text` — the text to trim.
- Returns the text without leading or trailing whitespace.

```kiru
std::io::print(std::text::trim("  hi\n"));   # hi
```

</details>

<details>
<summary><code>split</code> — split text into a list</summary>

```kiru
std::text::split(txt text, txt separator) -> list
```

- `text` — the text to split.
- `separator` — the text between parts. An empty separator splits between
  characters.
- Returns the parts as a list.

```kiru
list parts = std::text::split("a,b,c", ",");
```

</details>

<details>
<summary><code>lines</code> — split text into lines</summary>

```kiru
std::text::lines(txt text) -> list
```

- `text` — the text to split on newlines.
- Returns the lines as a list. A trailing newline adds no empty line.

```kiru
list lines = std::text::lines("a\nb\n");
```

</details>

<details>
<summary><code>contains</code> — whether text contains a needle</summary>

```kiru
std::text::contains(txt text, txt needle) -> txt
```

- `text` — the text to search.
- `needle` — the text to find.
- Returns `"true"` or `"false"`.

```kiru
std::io::print(std::text::contains("hello", "ell"));   # true
```

</details>

<details>
<summary><code>starts_with</code> — whether text starts with a prefix</summary>

```kiru
std::text::starts_with(txt text, txt prefix) -> txt
```

- `text` — the text to test.
- `prefix` — the expected start.
- Returns `"true"` or `"false"`.

```kiru
std::io::print(std::text::starts_with("hello", "he"));   # true
```

</details>

<details>
<summary><code>ends_with</code> — whether text ends with a suffix</summary>

```kiru
std::text::ends_with(txt text, txt suffix) -> txt
```

- `text` — the text to test.
- `suffix` — the expected end.
- Returns `"true"` or `"false"`.

```kiru
std::io::print(std::text::ends_with("hello", "lo"));   # true
```

</details>

<details>
<summary><code>replace</code> — replace every occurrence</summary>

```kiru
std::text::replace(txt text, txt from, txt to) -> txt
```

- `text` — the source.
- `from` — the text to replace. An empty `from` wraps every character.
- `to` — the replacement.
- Returns a new text.

```kiru
std::io::print(std::text::replace("a-b-c", "-", "+"));   # a+b+c
```

</details>

<details>
<summary><code>join</code> — join a list into one text</summary>

```kiru
std::text::join(list parts, txt separator) -> txt
```

- `parts` — the list to join.
- `separator` — the text between each pair.
- Returns the joined text.

```kiru
std::io::print(std::text::join(["a", "b"], "-"));   # a-b
```

</details>
