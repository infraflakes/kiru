---
title: std::set
description: The Set record and its methods.
---

`std::set` declares the `Set<K>` record and the set methods. `Set` is an
ordinary `rec` over a vec of keys kept sorted by a comparator it carries, so a
function whose first parameter is a `Set<K>` is callable as `s.name(...)`.
`use std::set;` brings the type and the methods into scope; a qualified
`std::set::Set` names the type without it, but the methods still need the `use`.
Both of `Set`'s fields, `entries` and `less`, are private to `std::set`, so a set
is built and read only through the methods below. [Sets](/concepts/sets/) covers
the narrative.

```kiru
use std;
use std::vec;
pub rec Set<K> { entries: Vec<K>, less: fn(K, K) -> bool };
```

A set orders by the comparator it carries, not by a bound: kiru has no bounds
and the checker rejects ordering a type parameter, so `less` is a value, exactly
as `sorted_by` takes one. Two keys are the same when `==` answers `true`; `less`
fixes their order. Every method below takes the set as its receiver.

<details>
<summary><code>of</code> — a set from a vec of keys</summary>

```kiru
std::set::of<K>(items: Vec<K>, less: fn(K, K) -> bool) -> Set<K>
```

- `items` — the keys to build from.
- `less` — the comparator that orders them.
- Returns a new set with `items` sorted by `less` and duplicates dropped.

```kiru
use std;
use std::text;
use std::set;
use std::vec;
fn main() {
  let s: Set<txt> = std::set::of(["b", "a", "a"], std::vec::text_less);
  std::print("@(s.len())");   # 2
};
```

`of` sorts with `sorted_by` and then drops adjacent duplicates, so one of each
key survives.

</details>

<details>
<summary><code>insert</code> — a new set with one key inserted</summary>

```kiru
s.with(item: K) -> Set<K>
```

- `item` — the key to insert.
- Returns a new set with `item` in order. A key already present is ignored, so
  the result is the same set and the set it is called on is unchanged.

```kiru
use std;
use std::text;
use std::set;
use std::vec;
fn main() {
  let s: Set<txt> = std::set::of(["a", "c"], std::vec::text_less);
  let n: Set<txt> = s.with("b");
  std::print(std::join(n.items(), ","));   # a,b,c
};
```

`with` binary-searches for the position, so it is O(log n).

</details>

<details>
<summary><code>contains</code> — whether a key is present</summary>

```kiru
s.contains(item: K) -> bool
```

- `item` — the key to test.
- Returns `true` or `false`. The binary search narrows with `less`, then `==`
  confirms the candidate, so it is O(log n).

```kiru
use std;
use std::text;
use std::set;
use std::vec;
fn main() {
  let s: Set<txt> = std::set::of(["a", "b"], std::vec::text_less);
  std::print("@(s.contains("a")) @(s.contains("z"))");   # true false
};
```

</details>

<details>
<summary><code>remove</code> — a new set without one key</summary>

```kiru
s.without(item: K) -> Set<K>
```

- `item` — the key to remove.
- Returns a new set without `item`. A key that is not present leaves the set
  unchanged.

```kiru
use std;
use std::text;
use std::set;
use std::vec;
fn main() {
  let s: Set<txt> = std::set::of(["a", "b", "c"], std::vec::text_less);
  let n: Set<txt> = s.without("b");
  std::print(std::join(n.items(), ","));   # a,c
};
```

</details>

<details>
<summary><code>union</code> — the keys of both sets</summary>

```kiru
s.union(other: Set<K>) -> Set<K>
```

- `other` — the set to merge.
- Returns a new set with every key of `s` and of `other`; a key in both appears
  once. The two sorted vecs are merged in one pass, ordered by `s`'s comparator.

```kiru
use std;
use std::text;
use std::set;
use std::vec;
fn main() {
  let a: Set<txt> = std::set::of(["a", "b"], std::vec::text_less);
  let b: Set<txt> = std::set::of(["b", "c"], std::vec::text_less);
  std::print(std::join(a.union(b).items(), ","));   # a,b,c
};
```

</details>

<details>
<summary><code>intersection</code> — the keys of both sets</summary>

```kiru
s.intersection(other: Set<K>) -> Set<K>
```

- `other` — the set to compare.
- Returns a new set of the keys present in both, merged in one pass and ordered
  by `s`'s comparator.

```kiru
use std;
use std::text;
use std::set;
use std::vec;
fn main() {
  let a: Set<txt> = std::set::of(["a", "b"], std::vec::text_less);
  let b: Set<txt> = std::set::of(["b", "c"], std::vec::text_less);
  std::print(std::join(a.intersection(b).items(), ","));   # b
};
```

</details>

<details>
<summary><code>difference</code> — the keys only in this set</summary>

```kiru
s.difference(other: Set<K>) -> Set<K>
```

- `other` — the set to subtract.
- Returns a new set of the keys of `s` that are not in `other`, merged in one
  pass and ordered by `s`'s comparator.

```kiru
use std;
use std::text;
use std::set;
use std::vec;
fn main() {
  let a: Set<txt> = std::set::of(["a", "b"], std::vec::text_less);
  let b: Set<txt> = std::set::of(["b", "c"], std::vec::text_less);
  std::print(std::join(a.difference(b).items(), ","));   # a
};
```

</details>

<details>
<summary><code>is_subset</code> — whether every key is in another set</summary>

```kiru
s.is_subset(other: Set<K>) -> bool
```

- `other` — the set to test against.
- Returns `true` when every key of `s` is also a key of `other`. The sorted vecs
  are walked in one pass; the first key of `s` that `other` passes is absent.

```kiru
use std;
use std::text;
use std::set;
use std::vec;
fn main() {
  let small: Set<txt> = std::set::of(["a"], std::vec::text_less);
  let big: Set<txt> = std::set::of(["a", "b"], std::vec::text_less);
  std::print("@(small.is_subset(big)) @(big.is_subset(small))");   # true false
};
```

</details>

<details>
<summary><code>len</code> — the number of keys</summary>

```kiru
s.len() -> int
```

- Returns the key count.

```kiru
use std;
use std::text;
use std::set;
use std::vec;
fn main() {
  let s: Set<txt> = std::set::of(["a", "b", "b"], std::vec::text_less);
  std::print("@(s.len())");   # 2
};
```

</details>

<details>
<summary><code>items</code> — the keys, in order</summary>

```kiru
s.items() -> Vec<K>
```

- Returns a new vec of the keys, in the order `less` gives them.

```kiru
use std;
use std::text;
use std::set;
use std::vec;
fn main() {
  let s: Set<txt> = std::set::of(["c", "a", "b"], std::vec::text_less);
  std::print(std::join(s.items(), ","));   # a,b,c
};
```

</details>
