---
title: Set
description: The Set record and its methods.
---

`Set<K>` is a declared `rec` in `std::dynamic`, a vec of keys kept sorted by a
comparator it carries. A method whose first parameter is a `Set<K>` is callable
as `s.name(...)`; an associated function is reached as `Set.name(...)`.
`use std::dynamic;` brings the type and its methods into scope, and a qualified
`std::dynamic::Set` names the type without it. Both of `Set`'s fields, `entries`
and `less`, are private to `std::dynamic`, so a set is built and read only
through the methods below. [Sets](/concepts/sets/) covers the narrative.

```text
use std;
use std::dynamic::Vec;
pub rec Set<K> { entries: Vec<K>, less: fn(K, K) -> bool };
```

A set orders by the comparator it carries, not by a bound: kiru has no bounds
and the checker rejects ordering a type parameter, so `less` is a value, exactly
as `sort_by` takes one. Two keys are the same when `==` answers `true`; `less`
fixes their order. Every method below takes the set as its receiver.

<details>
<summary><code>new</code> — the empty set</summary>

```text
std::dynamic::Set.new<K>(less: fn(K, K) -> bool) -> Set<K>
```

- `less` — the comparator that orders the keys.
- Returns a set with no keys.

```kiru
use std;
use std::dynamic::Set;
fn main() {
  let s: Set<txt> = Set.new(std::dynamic::text_order);
  std::print("@(s.len())");   # 0
};
```

</details>

<details>
<summary><code>from_items</code> — a set from a vec of keys</summary>

```text
std::dynamic::Set.from_items<K>(items: Vec<K>, less: fn(K, K) -> bool) -> Set<K>
```

- `items` — the keys to build from.
- `less` — the comparator that orders them.
- Returns a new set with `items` sorted by `less` and duplicates dropped.

```kiru
use std;
use std::dynamic::{Set, Vec};
fn main() {
  let items: Vec<txt> = Vec.new();
  items = items.push("b");
  items = items.push("a");
  items = items.push("a");
  let s: Set<txt> = Set.from_items(items, std::dynamic::text_order);
  std::print("@(s.len())");   # 2
};
```

`from_items` sorts with `sort_by` and then drops adjacent duplicates, so one of
each key survives.

</details>

<details>
<summary><code>insert</code> — a new set with one key inserted</summary>

```text
s.insert(item: K) -> Set<K>
```

- `item` — the key to insert.
- Returns a new set with `item` in order. A key already present is ignored, so
  the result is the same set and the set it is called on is unchanged.

```kiru
use std;
use std::dynamic::Set;
fn main() {
  let s: Set<txt> = Set.new(std::dynamic::text_order);
  s = s.insert("a");
  s = s.insert("c");
  let n: Set<txt> = s.insert("b");
  std::print(n.items().join(","));   # a,b,c
};
```

`insert` binary-searches for the position, so it is O(log n).

</details>

<details>
<summary><code>contains</code> — whether a key is present</summary>

```text
s.contains(item: K) -> bool
```

- `item` — the key to test.
- Returns `true` or `false`. The binary search narrows with `less`, then `==`
  confirms the candidate, so it is O(log n).

```kiru
use std;
use std::dynamic::Set;
fn main() {
  let s: Set<txt> = Set.new(std::dynamic::text_order);
  s = s.insert("a");
  s = s.insert("b");
  std::print("@(s.contains("a")) @(s.contains("z"))");   # true false
};
```

</details>

<details>
<summary><code>remove</code> — a new set without one key</summary>

```text
s.remove(item: K) -> Set<K>
```

- `item` — the key to remove.
- Returns a new set without `item`. A key that is not present leaves the set
  unchanged.

```kiru
use std;
use std::dynamic::Set;
fn main() {
  let s: Set<txt> = Set.new(std::dynamic::text_order);
  s = s.insert("a");
  s = s.insert("b");
  s = s.insert("c");
  let n: Set<txt> = s.remove("b");
  std::print(n.items().join(","));   # a,c
};
```

</details>

<details>
<summary><code>union</code> — the keys of both sets</summary>

```text
s.union(other: Set<K>) -> Set<K>
```

- `other` — the set to merge.
- Returns a new set with every key of `s` and of `other`; a key in both appears
  once. The two sorted vecs are merged in one pass, ordered by `s`'s comparator.

```kiru
use std;
use std::dynamic::Set;
fn main() {
  let a: Set<txt> = Set.new(std::dynamic::text_order).insert("a").insert("b");
  let b: Set<txt> = Set.new(std::dynamic::text_order).insert("b").insert("c");
  std::print(a.union(b).items().join(","));   # a,b,c
};
```

</details>

<details>
<summary><code>intersection</code> — the keys of both sets</summary>

```text
s.intersection(other: Set<K>) -> Set<K>
```

- `other` — the set to compare.
- Returns a new set of the keys present in both, merged in one pass and ordered
  by `s`'s comparator.

```kiru
use std;
use std::dynamic::Set;
fn main() {
  let a: Set<txt> = Set.new(std::dynamic::text_order).insert("a").insert("b");
  let b: Set<txt> = Set.new(std::dynamic::text_order).insert("b").insert("c");
  std::print(a.intersection(b).items().join(","));   # b
};
```

</details>

<details>
<summary><code>difference</code> — the keys only in this set</summary>

```text
s.difference(other: Set<K>) -> Set<K>
```

- `other` — the set to subtract.
- Returns a new set of the keys of `s` that are not in `other`, merged in one
  pass and ordered by `s`'s comparator.

```kiru
use std;
use std::dynamic::Set;
fn main() {
  let a: Set<txt> = Set.new(std::dynamic::text_order).insert("a").insert("b");
  let b: Set<txt> = Set.new(std::dynamic::text_order).insert("b").insert("c");
  std::print(a.difference(b).items().join(","));   # a
};
```

</details>

<details>
<summary><code>is_subset</code> — whether every key is in another set</summary>

```text
s.is_subset(other: Set<K>) -> bool
```

- `other` — the set to test against.
- Returns `true` when every key of `s` is also a key of `other`. The sorted vecs
  are walked in one pass; the first key of `s` that `other` passes is absent.

```kiru
use std;
use std::dynamic::Set;
fn main() {
  let small: Set<txt> = Set.new(std::dynamic::text_order).insert("a");
  let big: Set<txt> = Set.new(std::dynamic::text_order).insert("a").insert("b");
  std::print("@(small.is_subset(big)) @(big.is_subset(small))");   # true false
};
```

</details>

<details>
<summary><code>len</code> — the number of keys</summary>

```text
s.len() -> int
```

- Returns the key count.

```kiru
use std;
use std::dynamic::Set;
fn main() {
  let s: Set<txt> = Set.new(std::dynamic::text_order).insert("a").insert("b").insert("b");
  std::print("@(s.len())");   # 2
};
```

</details>

<details>
<summary><code>items</code> — the keys, in order</summary>

```text
s.items() -> Vec<K>
```

- Returns a new vec of the keys, in the order `less` gives them.

```kiru
use std;
use std::dynamic::Set;
fn main() {
  let s: Set<txt> = Set.new(std::dynamic::text_order).insert("c").insert("a").insert("b");
  std::print(s.items().join(","));   # a,b,c
};
```

</details>
