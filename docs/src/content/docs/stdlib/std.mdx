---
title: std
description: The builtins at the std root.
---

`std::` holds the builtins used most often: output. The categories hold the
rest: `std::process`, `std::syscalls`, `std::fs`, `std::text`, `std::dynamic`,
and `std::cli`.

The intrinsic types are `txt`, `bool`, and `int`: the language's scalar types,
visible in every namespace. Everything else is a declaration. `Vec<T>` and
`HashMap<K, V>` are declared in `std::dynamic`; `Option<T>` is declared in
`std`; and each is reached by its path or with a `use`.

<details>
<summary><code>print</code> — write a line to stdout</summary>

```text
std::print(message: txt)
```

Writes `message` to stdout with a trailing newline.

```kiru
use std;
fn main() {
  std::print("hello");
};
```

</details>

<details>
<summary><code>log</code> — write an INFO line</summary>

```text
std::log(message: txt)
```

Writes an `INFO:` line to stdout; the prefix is yellow when stdout is a
terminal.

```kiru
use std;
fn main() {
  std::log("starting");
};
```

</details>

<details>
<summary><code>eprint</code> — write an ERROR line and stop the run</summary>

```text
std::eprint(message: txt)
```

Writes an `ERROR:` line to stderr, red when stderr is a terminal, then stops the
run. Because `eprint` always stops the run, calling it never returns.

```kiru
use std;
fn report(message: txt) -> txt {
  std::eprint(message);
};
fn main() {
  std::print("ready");
};
```

Related: [Panic and Failure](/failure/panic/).

</details>

The command builder and `quote` live in [std::process](/stdlib/process/); the
path helpers and file reads in [std::fs](/stdlib/fs/); the text methods in
[std::text](/stdlib/text/); the containers in [Vec](/stdlib/vec/) and
[HashMap](/stdlib/hashmap/); and the optional value in
[std::Option](/stdlib/option/).
