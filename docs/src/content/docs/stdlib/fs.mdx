---
title: std::fs
description: Read and write files, expand globs, and split paths.
---

`std::fs` reads and writes files and works with paths. A path is plain text, so
[std::text](/stdlib/text/) works on it too, and every path function splits on
POSIX `/` separators. The two file operations are natives here, beside the path
helpers, because reading and writing a path is a file operation rather than a
syscall; removing a file and testing a path are the
[std::syscalls](/stdlib/syscalls/) natives `unlink` and `access`.

<details>
<summary><code>read</code> — read a whole file</summary>

```text
std::fs::read(path: txt) -> txt
```

Reads a whole file as text.

- `path` — the file to read.
- Returns its contents. A file whose bytes are not UTF-8, and a file that cannot
  be read, stop the run.

```kiru
use std;
fn main() {
  let path: txt = std::fs::temp_file();
  std::fs::write(path, "hello\n");
  std::print(std::fs::read(path));
  std::syscalls::unlink(path);
};
```

</details>

<details>
<summary><code>write</code> — replace a file with text</summary>

```text
std::fs::write(path: txt, text: txt)
```

Replaces a file with text, creating it when absent.

- `path` — the file to write.
- `text` — the new contents.

```kiru
use std;
fn main() {
  let path: txt = std::fs::temp_file();
  std::fs::write(path, "hello\n");
  std::syscalls::unlink(path);
  std::print("written");
};
```

</details>

<details>
<summary><code>append</code> — append text to a file</summary>

```text
std::fs::append(path: txt, text: txt)
```

Appends text to a file, creating it when absent. The append is not atomic
across concurrent writers.

- `path` — the file to append to.
- `text` — the text to add.

```kiru
use std;
fn main() {
  let path: txt = std::fs::temp_file();
  std::fs::write(path, "a\n");
  std::fs::append(path, "b\n");
  std::print(std::fs::read(path));
  std::syscalls::unlink(path);
};
```

</details>

<details>
<summary><code>temp_file</code> — create a unique empty file</summary>

```text
std::fs::temp_file() -> txt
```

Creates an exclusive, owner-only empty file under `$TMPDIR` (falling back to
`/tmp`) and returns its path.

- Returns the path as text. The caller owns the file and must remove it.

```kiru
use std;
fn main() {
  let path: txt = std::fs::temp_file();
  std::fs::write(path, "scratch");
  std::syscalls::unlink(path);
  std::print("done");
};
```

</details>

<details>
<summary><code>glob</code> — expand a glob into a Vec</summary>

```text
std::fs::glob(pattern: txt) -> Vec<txt>
```

Expands a glob pattern into a vec of matching paths.

- `pattern` — supports `*`, `?`, `[...]`, and `**`.
- Returns the matches in sorted order.

```kiru
use std;
use std::dynamic::Vec;
fn main() {
  let files: Vec<txt> = std::fs::glob("*.kiru");
  std::print("@(files.len())");
};
```

</details>

<details>
<summary><code>is_dir</code> — whether a path names a directory</summary>

```text
std::fs::is_dir(path: txt) -> bool
```

Tests whether a path names a directory.

- `path` — the path to test.
- Returns `true` when it names a directory, `false` for a file or a path that
  does not exist.

```kiru
use std;
fn main() {
  match std::fs::is_dir("/tmp") {
    true => { std::print("a directory"); };
    _ => { std::print("not a directory"); };
  };
};
```

</details>

<details>
<summary><code>is_absolute</code> — whether a path is absolute</summary>

```text
std::fs::is_absolute(path: txt) -> bool
```

- `path` — the path to test.
- Returns `true` when the path starts with `/`, otherwise `false`.

```kiru
use std;
fn main() {
  std::print("@(std::fs::is_absolute("/a"))");
};
```

</details>

<details>
<summary><code>join</code> — join two path segments</summary>

```text
std::fs::join(base: txt, name: txt) -> txt
```

Joins two path segments. An absolute `name` replaces `base`, an empty `base` is
replaced by `name`, and a `base` already ending in `/` is used as is.

- `base`, `name` — the segments to join.
- Returns the joined path.

```kiru
use std;
fn main() {
  std::print(std::fs::join("/home/dev", ".config"));
};
```

</details>

<details>
<summary><code>base</code> — the last segment</summary>

```text
std::fs::base(path: txt) -> txt
```

- `path` — the path to read.
- Returns the text after the last `/`; the whole path when it has no `/`. An
  empty path has no segment, so it stops the run.

```kiru
use std;
fn main() {
  std::print(std::fs::base("/a/b/c"));   # c
};
```

</details>

<details>
<summary><code>dir</code> — a path without its last segment</summary>

```text
std::fs::dir(path: txt) -> txt
```

- `path` — the path to read.
- Returns the text before the last `/`, or `""` when there is none; an empty
  path has none.

```kiru
use std;
fn main() {
  std::print(std::fs::dir("/a/b/c"));   # /a/b
};
```

</details>

<details>
<summary><code>ext</code> — the extension</summary>

```text
std::fs::ext(path: txt) -> std::Option<txt>
```

- `path` — the path to read.
- Returns the text after the last `.` of the last segment as `Option.some`, or
  `Option.none` when the last segment has no dot.

```kiru
use std;
fn main() {
  std::print(std::fs::ext("archive.tar.gz").or(""));   # gz
};
```

</details>
