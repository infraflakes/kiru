Welcome to *The Kiru Programming Language*.

Kiru is a small, statically typed language for orchestrating processes: running
commands, handling the data they produce, and tying steps together. A Kiru
program compiles to one self-contained binary.

This book teaches Kiru from the ground up. You don't need any prior Kiru, but
you should be comfortable with a command line and with another programming
language.

## How to Read This Book

The book is meant to be read in order. [Getting
Started](/getting-started/installation/) gets you installed and running,
[A First Program](/getting-started/a-first-program/) builds a small working
program, and the chapters after that explain each part in more depth. You can
start writing useful Kiru in the second chapter.

If you want to look something up, the [standard
library](/stdlib/process/) reference and the appendices at the end cover the
whole surface.

## What Kiru Looks Like

Here is a complete Kiru program:

```kiru
fn main(rec args) {
  switch(args.cmd) {
    case("test") { std::io::print(std::process::command({}, "cargo test")); };
    default { std::io::eprint("usage: test"); };
  };
};
```

`main` reads the command line, `switch` chooses a branch, and
`std::process::command` runs a command and returns its exit code.
[A First Program](/getting-started/a-first-program/) walks through a program
like this one.
