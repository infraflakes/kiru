---
title: Modules and Namespaces
description: Files, namespaces, imports, and the entry file.
---

This chapter covers how a program is split across files. It describes the
namespace a file belongs to, the value and function registries a namespace
holds, imports and the paths they make reachable, the rooted `::` that
names the root, the reserved `std` namespace, and the entry file whose
`main` a compiled program runs.
