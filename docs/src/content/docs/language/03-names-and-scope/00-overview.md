---
title: Names, Scope, and Assignment
description: Declaration order, unique names, assignment, scopes, and module values.
---

This chapter explains how names work. It covers the top-down declaration
order, the rule that a value name and a function name are each unique in a
namespace, the rooted `::` that names the root, assignment and read-only
parameters, the bodies and scopes that share bindings, and module values
that are evaluated once at startup.
